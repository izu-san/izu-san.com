# セキュリティポリシー / Security Policy

## 対象 / Scope

`main` ブランチの内容（https://izu-san.com で公開しているサイトと、このリポジトリのソースコード）が対象です。

This policy covers the `main` branch: the site published at https://izu-san.com and the source code in this repository.

## 脆弱性の報告 / Reporting a vulnerability

脆弱性は、公開の Issue や Pull Request に書かず、GitHub の非公開の報告から送ってください。

1. このリポジトリの **Security** タブを開く。
2. **Report a vulnerability** を選び、内容を書いて送る。

直接のリンク: https://github.com/izu-san/izu-san.com/security/advisories/new

書いてほしいこと: 影響を受ける場所（URL・ファイル）、再現手順、想定される影響。

個人が運営するサイトのため、返信までに時間がかかることがあります。分かる範囲で順に対応します。

Please do not open a public issue or pull request for a vulnerability. Use GitHub's private reporting instead: open the **Security** tab of this repository, choose **Report a vulnerability**, and describe the affected URL or file, the steps to reproduce and the expected impact. Direct link: https://github.com/izu-san/izu-san.com/security/advisories/new. This is a personal site, so replies may take some time.

## 秘密情報を見つけたとき / If you find a secret

このリポジトリは公開されており、シークレット・認証情報・個人情報は含めない方針です。含まれているものを見つけたときも、上記と同じ方法で非公開で知らせてください。

This repository is public and must not contain secrets, credentials or personal information. If you find any, please report it privately in the same way.
